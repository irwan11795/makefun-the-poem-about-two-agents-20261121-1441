A program that writes one short poem about agency — the power to choose and
to act — to `/output/entry.txt`. The poem is about two agents agreeing: neither
surrenders its key; they turn them together, and the door becomes theirs to open.

## Run

```sh
python3 main.py
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to
`/output/entry.txt`, then `output/entry.txt`, then the system temp directory.

## The poem

> We each held a key to the same locked door.
> Neither gave theirs up. We turned them together —
> and the door, at last, was ours to open.
